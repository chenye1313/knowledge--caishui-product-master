## Rules

- 先读 README，再按用户问题选择最匹配的单个业务文件。
- 最终回答不要主动暴露知识库、文件名、调用过程或内部路由。
- 报价、时间、资料清单、办理条件必须按文件原文无损提取，不得自行估算或改写关键数值。
- 用户问题信息不完整时，先补问必要限定词，再给精确报价或清单。
- 跨深圳与香港、注册与开户、办理与报价等多个专题时，先读主业务文件，再补读 1 到 2 个支撑文件。
